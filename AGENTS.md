# vega-gated-video-player

Body-aware video for Fire TV (Vega OS): a React Native player that pauses at .istep gates and resumes when live pose or hand landmarks pass them. Open format + pure-TS gate engine. MIT.

Package manager: npm.

## Commands

- test: `npm test`
- typecheck: `npm run typecheck`

## Layout

- `demo/`
- `docs/`
- `example/`
- `examples/`
- `schema/`
- `src/`
- `test-fixtures/`

## Rules

- Run `npm test` before you say a change is done.
- Never commit secrets or `.env` files.
